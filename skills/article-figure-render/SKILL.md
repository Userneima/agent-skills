# 文章插图生成（出图侧）

这是**出图侧**。需求方给意图与禁区、并做最终验收，那一侧在 `article-visuals`；本 skill 只管一件事：**把简报变成图，并保证图上每一个字都真的画出来了、每一句都念得通**。

在 macOS 上用 Python 的 PIL 出图时总结出来的，字体的例子都是苹方。用 HTML 或 SVG 出图、或者在别的系统上，第一节缺字自检照样要做，字体要换成你那边覆盖简体中文的那款。

分工不要反过来：版式（构图、配色、字号、留白）归你，图上的**文字内容**逐字照简报走。需求方给的标签不要润色——把「提供方」改成「服务提供者」是这条路上最常见的越界。

## 一、开工第一件事：缺字自检，不是最后一件

**字体缺字是静默失败。** PIL 不警告、不报错，那个字就是没了，图看着完全正常——直到有人把图上的句子念一遍。所以自检必须在渲染前跑，而且是脚本跑，不是自己看。

```bash
# 1. 先看清字体文件里有哪几个 face，不要猜 index
scripts/check_glyph_coverage.py --font <字体路径> --list-faces

# 2. 用最终 face 扫一遍出图脚本里所有字符串字面量
scripts/check_glyph_coverage.py --font <字体路径> --index <N> render.py
```

缺字时它退出 1 并告诉你缺哪个字、在第几行。**非零就不出图。**

把它接进出图脚本的入口（渲染前调用，非零直接 `sys.exit`），比写在文档里靠人记得住可靠得多。

### macOS PingFang 的 index 陷阱（真实事故，2026-08-18）

`PingFang.ttc` 是**字体集合**，一个文件里装了 12 个 face，`index` 决定语言变体：

| index | 0 | 1 | 2 | 3 | 4–7 | 8–11 |
|---|---|---|---|---|---|---|
| face | HK | MO | TC | **SC** | 同序 Medium | 同序 Semibold |

所以简体正文要用 `index=3`（Regular）／`7`（Medium）／`11`（Semibold）。**`index=0` 是 PingFang HK（繁体）**，而 HK / MO / TC 都没有简体独有字形——「稳」「杀」这类字直接渲染成空白。

事故经过：一批五张说明图用 `index=0` 出图，三处字消失（药丸里的「稳定」少了「稳」、「越长越不稳」少了「稳」、「杀伤不均匀」少了「杀」）。图交付、插进文档、走完一轮验收都没被发现，是人在读图时看出来的。用上面的脚本扫同一份脚本，两秒定位。

两条推论：

- **换字体或换 face，整批图必须重出。** SC 与 HK 部分共用码位的字形并不相同，只重出出问题的那几张，会让一篇文章里混着两套字形。
- **走 HTML / 浏览器截图的失败模式不同**：浏览器会自动 fallback 到别的字体，所以不缺字，但会出现同一张图里几种字形混排。那条路上要检查的是 `font-family` 是否真的命中，而不是缺字。

## 二、中文换行禁则

自己实现的 wrap 函数只按宽度断行，会把标点推到行首。中文行首禁则要求这些字符不起行：

```
，。、；：！？）」』】》"' ·
```

同一批图里只要有一处出现，就是没做这一步——这类问题总是成片出现，不是偶发。

## 三、出图后：自己把图打开看

不要凭「渲染成功」交付。每张图逐条过：

1. 图上的字从头念一遍，有空框、缺字、读不通的词，就是没画完。
2. 关系有没有画反（把「三个必须同时成立的条件」画成一条先后箭头链是最典型的）。
3. 有没有冒出简报里没有的东西——尤其是没标来源的数据、曲线、案例。
4. 专有名词（命令名、skill 名、字段名、版本号）回仓库核一遍还在不在、还叫不叫这个名字。图是静态的，正文改了它不跟着改，而且**搜正文搜不到图里的字**。

## 四、交付

- **一批图一次出全**，同一套视觉语言。分次交等于每次重新定一套风格。
- 需求方必须能亲眼看到图：存到指定路径，或直接插进文档指定位置，不要只描述。
- 插进飞书文档时要注意：媒体 token 不能跨块复用、`block_replace` 会换新 id、`ok: true` 不等于写进去了。装了 `feishu-doc-ops` 的话，它的 `references/feishu-docx-block-editing.md` 末节有完整清单。

## 五、已知限制

- 不带现成的渲染骨架（坐标体系、画布尺寸、换行和居中 helper），出图脚本按各自的渲染路径自己写。
- 不规定配色和字重，那是版式，归出图方定。
- 字体例子只覆盖 macOS 的 PingFang。其他系统先选一款覆盖简体的字体，用 `--list-faces` 看清 face，再跑缺字自检。
